# 修行体验蓝图

记录《问道》从“自律记录 App”走向“个人修行世界”的长期产品方向。本页为规划文档，除明确标注已完成的能力外，内容均为待实现方案。身份、测灵、授法剧情、一分钟起念/养息、归山引导与「未熄之灯」剧情首卷已接入，后续仍可深化长线仪式。

## 核心命题

《问道》不只帮助玩家完成任务，更要帮助玩家回答：

> 我此刻想修成什么样的人？

设计原则：

- 先让玩家选择方向，再让真实行动印证方向；不要求坚持数十日后才给予身份反馈。
- 灵根、道途与功法分层表达，避免把现实行为机械归类。
- 修为体现总进度；功法成长、道途印记和环境变化体现个人经历。
- 鼓励“愿意开始”和“愿意归来”，不把断签处理成羞辱或惩罚。
- 任何出生信息只用于游戏内设定，不上传服务器，也不用于现实命理解读。

## 三层修行结构

| 层级 | 游戏含义 | 现实映射 | 例子 |
|---|---|---|---|
| 灵根 | 先天气象、主题底色 | 入门身份与审美选择 | 青木、赤火、玄水、庚金、厚土 |
| 道途 | 主修方向、叙事路线 | 玩家想成为的自己 | 剑修、体修、丹修、符修、阵修 |
| 功法 | 每日实际修炼手段 | 自定义活动模板 | 背单词、跑步、早睡、写论文 |

同一现实活动可以被不同道途包装。例如“专注学习 25 分钟”：

| 道途 | 功法包装 |
|---|---|
| 剑修 | 观剑悟意 |
| 丹修 | 辨药炼识 |
| 符修 | 临摹玄篆 |
| 阵修 | 推衍阵图 |

因此，道途提供故事口吻与推荐方案，不限制玩家创建哪些现实活动。

## 开局：测灵台与问心台

### 两条入门路径

| 路径 | 操作 | 结果 |
|---|---|---|
| 测灵台 | 输入出生年、月、日、时 | 本地排出四柱八字，以日主五行定先天灵根 |
| 问心台 | 不提交出生信息，直接自选 | 由玩家选择此刻最想认领的灵根 |

### 测灵台边界

- 完整排盘必须使用年、月、日、时四项，并接入成熟的本地历法实现，正确处理节气换月等边界。
- 初期仅取日主五行对应灵根：`甲乙 -> 木`、`丙丁 -> 火`、`戊己 -> 土`、`庚辛 -> 金`、`壬癸 -> 水`。
- 不判断五行强弱、喜用神、格局、吉凶或现实命运。
- 明文提示：`此处排盘仅用于游戏内灵根设定，不作现实命理解读。`
- 隐私默认：不保存原始出生时间，只保存用户选择保留的四柱文本、日主与灵根结果；始终提供问心台作为不输入生日的入口。

### 开局流程

1. 雨夜序幕引出无灯长夜，以“你想成为什么样的人？”邀请玩家叩响山门。
2. 闻钟展开灯册，玩家登记姓名 / 称呼，或以“无名来者”入山；道号留待日后获得认可再议。
3. 选择主修道途。
4. 对应引路人出场，解释灵根与选择的意义，并亲授三门入门功法。
5. 玩家领受功法后，由引路灯火引入静室；此处只供敛息候行，不提前计作完成功课。
6. 静室中的功课入口逐层显现；玩家亲手完成第一门现实功课，才正式触发首次引气剧情。

示例文案：

```text
命盘：壬申 · 庚戌 · 甲辰 · 丁卯
日主：甲木
灵根：青木灵根

天赋为引，道途由心。
请选择你的主修方向。
```

### 属性影响原则

- 第一阶段灵根与道途只影响主题光色、文案、推荐功法和机缘表现，不给予数值强弱差异。
- 若未来加入轻微加成，必须避免出现为了最优灵根而重开的压力。
- 玩家长期行为可以开启兼修或侧脉，但不应否定玩家开局选择的身份。

## 第一周：最重要的留存仪式

多数玩家不可能等待三十七日后才第一次收到系统回应。第一周必须有真实而不苛刻的认可。

| 仪式 | 条件建议 | 反馈 |
|---|---|---|
| 灵根引气 | 完成第一门功法 | 首次引气文案、微弱灵光反馈 |
| 生芽 / 初鸣 | 三日内完成任意两日功课 | 灵根第一次小变化或短寄语 |
| 七日守心 | 入门后七日内，有四天完成至少一门功课 | 印记、入门文书、道途初显 |
| 七日不辍 | 连续七日每天完成至少一门功课 | 稀有印记与更郑重的认可 |

`七日守心` 不要求完美连续，因为产品应该接住普通人的节奏，而不是只奖励满勤者。

文案示例：

```text
入门七日，道心未散。
修行不在一日勇猛，而在明日仍愿再来。
山门录你为外门弟子，自今日起，可择一途徐行。
```

## 功法成长

修为是整个人物的总进度，每门功法也应留下独立痕迹。

建议记录：

- 完成次数、累计投入分钟或累计完成数量。
- 最近修炼日、连续修炼段与历史最好记录。
- 功法境界：`初习 -> 初窥门径 -> 小成 -> 大成 -> 圆满`。
- 与道途相关的功法感悟、印记或极轻的视觉变化。

示例：

- `研读古籍` 完成 7 次：`初窥门径`。
- `淬体炼骨` 累计 300 分钟：获得 `气血充盈` 印记。
- `早睡守戒` 连续完成 7 日：获得 `清梦` 印记。

原则：断几天不会掉等级，也不会失去已经获得的印记；只会暂停新的成长。

## 起念：奖励愿意开始

现实中的难点常常不是完成，而是启动。为此增加一条比完整闭关更低门槛的入口：

### 起念模式

- 在一门计时功法上提供 `先修一分钟`。
- 一分钟结束后，玩家可以结束并领取很少但真实的修为，或转为完整闭关继续修行。
- 起念完成可计为“今日道心未断”，但不能等价于完成完整目标，也不应可无限刷取。

文案示例：

```text
一念既起，今日道心未断。
```

价值：帮助玩家面对拖延、畏难和状态不佳的开局，而不是要求他一开始就承诺高强度闭关。

## 养息日：状态低谷中的正途

自律产品不应只服务状态良好的日子。生病、加班、情绪低落时，玩家需要被允许转守。

### 养息机制

- 玩家可将今日切换为 `养息日`。
- 系统将今日推荐收缩为一门极小功课，例如喝水、五分钟散步、整理床铺或早点睡。
- 完成养息功课获得低量修为与“道心未散”记录，不视为高强度进展。
- 养息日不提供刷取优势，不替代连续高质量修行的特殊成就。

文案示例：

```text
修行有进有守，养息亦是正途。
```

这比“补签”更符合产品气质：不是修补一个失败记录，而是承认调息本身也属于长期修行。

## 守约功法：保留，但不作为核心增长

原“打卡”计量改称 `守约`。它适合早睡、睡前不刷手机、收拾桌面等难以用时长或数量表达、但有明确完成边界的承诺。

- 有自然计量的行为优先使用计时或数量，以保留真实投入感。
- 守约结算应较克制，同日只能领取一次，不成为快速刷修为入口。
- 养息时的轻功课可以使用守约，因为此时目的在于接住状态，而非追求高收益。

## 破境：修为门槛加现实试炼

境界若仅靠累计修为，玩家可能只通过大量低门槛功课突破。大境界突破可增加一次轻量、真实、可完成的试炼。

### 筑基之约

- 修为达到炼气圆满的筑基门槛后，不立刻进入筑基。
- 玩家从若干挑战中选择一个完成：
  - 七日内完成三次主修功法。
  - 完成一次 45 分钟专注闭关。
  - 完成一个符合其道途的同级挑战。
- 完成后触发筑基演出、突破文书与法相变化。

原则：

- 小境界仍可按修为自然推进，大境界才使用“破境之约”。
- 试炼必须有多种选项，让不同生活节奏的人都有合理路径。
- 试炼未完成只停在圆满，不扣修为、不掉境界。

## 环境叙事：让世界先于 NPC 回应玩家

剧情系统不急于先做大量文字弹窗。玩家的生活可以先让首页世界产生细小而持续的变化。

| 玩家行为 | 环境反馈 |
|---|---|
| 连续早睡或养息良好 | 夜雨渐退，晨雾、暖灯与清光增多 |
| 常修读书 / 学习 | 案边出现竹简、灯火或书页光影 |
| 常修运动 | 修士周身气血光色更温暖、有力 |
| 长期冥想 / 戒手机 | 水面更静、钟声更远、环境更澄澈 |
| 离山数日 | 庭院落叶渐多、炉火微弱，但绝不出现责备文案 |
| 归来完成一门功课 | 灯火重新亮起、环境恢复生机 |

这样，未来加入人物、宗门与事件线时，剧情将是行为塑造世界后的深化，而不是突兀的随机通知。

## 归山：中断后的第一次回来

用户一定会中断。最值得认真设计的不是如何惩罚断签，而是如何接住第一次归来。

### 归山仪式

- 若玩家离开若干日后再次进入 App，启动时直接出现安静的归山引导。
- 不展示失败天数，不要求补偿所有落下的功课。
- 直接提供一门计时功法的 `一分钟起念`，不要求先完成完整功课。

文案示例：

```text
山门旧灯尚燃。
你归来便好。
今日，可先从一息开始。
```

## 剧情系统的落地前提

庞大世界观仍然保留，但剧情不应先于行为系统开发。

剧情需要的行为输入：

- 已选灵根与主修道途。
- 主修功法及功法成长阶段。
- 七日守心、七日不辍等关键仪式结果。
- 养息、起念、归山及破境之约的历史。
- 不同类型活动长期形成的侧脉倾向。

有了这些输入，事件才能像回应玩家真实经历：

- 读书者获得藏经阁残卷。
- 炼体者在山门遇到武师。
- 守心者在雨夜听见钟声。
- 归来者见到一直未灭的山门灯火。

## 建议开发顺序

| 顺序 | 模块 | 目标 |
|---:|---|---|
| 1 | 入门身份骨架 | 问心台自选灵根、选择道途、推荐功法模板 |
| 2 | 第一周仪式 | 首次引气、三日回应、七日守心 / 不辍 |
| 3 | 起念与养息 | 支持低门槛启动和低谷修行 |
| 4 | 功法成长 | 独立熟练度、阶段、印记 |
| 5 | 测灵台排盘 | 离线四柱排盘与隐私处理 |
| 6 | 筑基之约 | 大境界现实试炼与突破文书 |
| 7 | 环境叙事 | 行为驱动首页场景变化 |
| 8 | 世界观与剧情 | 宗门、人物、事件线与行为分支 |
