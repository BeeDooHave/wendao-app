# 法相进阶设定

记录九大境界的法相视觉演进。**炼气已定稿,当前制定筑基**,其余七境后续逐境生图。

## 铁律

- **炼气是九境之底,法相压到最低**:初期几乎看不见,圆满也只是凝练而内敛的淡晕。
- 每升一个大境界,宏大度必须明显压过前一阶,给大乘、飞升留足空间。
- **人物主体始终不变**(`assets/home-cultivation-base-v2.webp` 里的盘坐修士)。法相是叠加层,大境界时可超出人物轮廓,但本体仍在。
- 颜色主线暖金贯穿;炼虚起掺冷色/虚空感,飞升回归圣金。
- 废弃原 `home-spirit-overlay-v1.webp` 与 `home-spirit-solid-qi-mid-v1.webp`(后者是写实白衣男子,与设定不符)。

## 筑基法相方案

### 境界定位

- 筑基不是把炼气气影单纯调亮,而是从"气在周身流动"转为"气有稳定根基",并在丹田点燃持续变化的紫焰。
- 相对炼气圆满,筑基初期就应出现新的可识别符号:**道基外环**。这是大境界突破后的即时反馈。
- 法相仍是既有人物身上的显化,不出现独立人脸、完整第二人或巨大神祇。
- 宏大度保持在 `2/10`:稳定、规整、可辨认,但仍贴近身体尺度,为金丹留出明显上升空间。

### 页面可见性约束

- 首页下方修为信息卡会遮挡人物腿部和座下中央区域,不能把筑基识别点只放在脚底或石台正中。
- 道基必须以扁椭圆外环向左右延展,使两侧边缘在信息卡上方或外侧仍能被看见。
- 身后增加低矮的开放式定息背环,位于头后至肩外区域;它是辅助识别点,不可发展成第二个人形。
- 底图、人物、坐姿和背景全部固定,筑基仍只叠加黑底 `screen` 法相层。

### 核心造型

| 组成 | 形态 | 边界 |
|---|---|---|
| 道基外环 | 修士座下展开一圈薄、稳、扁椭圆的暖金光环,左右边缘清晰可见 | 不画实体莲台,不做大面积发光地面 |
| 定息背环 | 头后至肩外的一圈低亮、开放式淡金气轮 | 不闭合成人像头轮,不压过道基外环 |
| 归脉光流 | 少量光丝由肩外向下内收,视觉上回流至道基 | 不再像炼气那样四散飘飞 |
| 丹田紫焰 | 腹前燃起一团小而不规则的紫焰特效资产,配合轻微呼吸明暗,作为筑基特有识别点 | 不使用纯 CSS 拼画火焰,不形成金丹实体珠,不扩展成大面积火海 |

### 四个小境界演化

| 阶段 | 主变化 | 应达到的观感 |
|---|---|---|
| 筑基初期 | 道基外环首次出现,仅一层薄环;丹田紫焰初燃,背环很淡 | 一眼可判断已不是炼气圆满,但仍内敛 |
| 筑基中期 | 道基外环连续稳定,紫焰更清晰;两三缕光流向基环归拢 | 根基已立,画面从飘忽转为安定 |
| 筑基后期 | 外环内侧浮现第二道极淡纹环,紫焰稳定跃动;背环更完整 | 有结构感但不华丽,仍没有实体法器或金丹 |
| 筑基圆满 | 双层道基环稳定发光,紫焰和归脉光流达到本境最清晰状态 | 为金丹聚光蓄势,但亮度和威仪明显低于金丹 |

### 资产与接入决策

- 筑基使用统一法相原画:`assets/home-fashang-foundation.webp`,并叠加紫焰资产:`assets/generated/foundation-purple-flame-v1.webp`。四小境界通过透明度、尺寸及呼吸亮度递进。
- 灵珠收束到法相周围,各自按随机半径、速度和方向进行圆周运转,形成灵动但不散乱的气机轨迹;炼气与筑基均按初/中/后/圆满显示 `0 / 1 / 2 / 3` 颗。
- 丹田紫焰保持完整资产固定锚在丹田,仅使用轻微透明度、饱和度与明暗呼吸,避免裁切或形变破坏火焰质感。
- 原画需要同时包含道基外环、淡背环和归脉光流;不能依赖信息卡遮住的中央底部细节表达境界。
- 若实机验证中道基外环仍被信息卡压住,再增加单独的 CSS 椭圆基环层作可见性修正;不在生图前预置多余层。
- 筑基初期的表现必须在移动端实际首页尺寸下明显区别于炼气圆满,否则不进入接线阶段。

### 验收标准

- 在首页实际裁切与信息卡覆盖下,筑基初期仍能识别出道基外环。
- 炼气圆满到筑基初期的差异来自"稳定根基"的新形态,而不是简单增亮。
- 筑基四阶始终是同一造型逐级凝实,不会出现阶段间换人物或换背景。
- 紫焰资产本身必须自然、不规则,轻微呼吸动效后仍成为炼气到筑基的第一识别点。
- 筑基圆满仍应弱于后续金丹的丹田金珠和饱满纯金光环。

## 资源与实现约定

- 炼气使用唯一法相图:`home-fashang-qi.webp`;初期近乎隐没,中期必须已可辨识为空心坐姿气影,后/圆满再以 CSS 透明度、亮度与模糊逐阶凝实,维持统一辨识度。
- 后续境界的法相资产数量按实际表现再定,但不得替换人物本体或以换背景模拟进阶。
- 与 `app.js` 中 `setRealmVisualState` 的 major + stage 分类对应。
- 法相图统一:纯黑底(供 `screen` 叠加)、竖屏、与底图修士坐姿位置对齐(生图时附 `home-cultivation-base-v2.webp` 作参考)。
- 后续命名建议:`home-fashang-{foundation,golden,nascent,deity,void,union,mahayana,tribulation}.webp`。
