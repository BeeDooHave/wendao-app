# 《问道》美术与演出指引

> 版本：M1 入门仪式与首次入室
> 更新日期：2026-05-27
> 适用范围：角色立绘、首页场景、剧情过场、法相、动效与后续 AI 生图

## 1. 视觉目标

《问道》的画面不是热闹的战力展示，而是一个人在雨夜重新愿意开始的时刻。视觉上应始终守住三点：

- **雨夜的幽深**：青黑、黛蓝、潮湿石阶与沉静留白构成主面积。
- **灯火的温度**：铜灯、烛芯、符火或器物微光是引导视线和叙事意义的核心。
- **克制的仙意**：灵气可见但不滥用粒子和耀斑；低境界尤其不应华丽到失去成长空间。

关键词：`vertical cinematic`、`rainy mountain sect`、`deep indigo night`、`restrained warm lantern`、`quiet xianxia`、`full-body character`。

避免方向：高饱和手游海报、满屏金光、密集颗粒噪点、游戏 UI 烧入图片、文字或水印、人物头像卡替代全身入场。

## 2. 色彩与材质

| 类别 | 方向 | 使用位置 |
|---|---|---|
| 主背景 | 深黛蓝、青黑、冷灰石色 | 雨夜、山门、静室、遮罩 |
| 叙事灯光 | 暖铜金、低饱和琥珀 | 闻钟提灯、石不言手灯、首页灯火 |
| 道途差异光 | 冷银、药青、符金、阵蓝 | 引路人法器局部与过场余光 |
| 灵气 | 半透明、边缘柔和、低亮度 | 首页修行反馈与低境界法相 |

材质偏好：湿石、旧木、青瓦、粗布、铜器、薄纸、墨迹。材质必须帮助构成安静的可触摸世界，而不是作为繁复装饰堆叠。

## 3. 构图规则

### 3.1 角色入场图

- 竖屏全身画幅，按手机全屏 `cover` 显示设计。
- 人物脸部与主要光源不可落在常见对话框覆盖区。
- 画面应预留底部暗部承载对话文本。
- 每位引路人都要有一个画面内真实存在的灯、火、符、炉或阵光锚点。
- 引路人显形阶段只使用同一张全屏画面，不另叠缩小头像或卡片图。

### 3.2 光源对齐

过场中“先见光，再见人”的光必须来自图中可辨认的位置。实现时：

- 以画面 `cover` 后的真实视觉位置校准 CSS 光晕坐标。
- 分别在窄屏与长屏验证，不能仅在开发桌面比例上对齐。
- 没有天然光源的构图不得直接接入；应先重画或加入合理器物光源。
- 光晕只负责引目，不应扩大到洗掉人物细节。

### 3.3 对话与遮挡

- 对话框位于画面下段，以深色半透明承载，不形成第二幅人物小窗。
- 字体和按钮留有呼吸感，不用大块高亮破坏夜色。
- 对话演出优先显示人物，再逐渐释放信息控件；不要在人物第一次出现时堆满功能说明。

## 5. 当前演出规范

### 5.1 山门序幕

```text
黑场字幕逐页点击
  -> 叙述主角在雨夜上山的理由
  -> 山门画面显现
  -> “你想成为什么样的人？”
  -> 玩家叩响山门
```

节奏：宁可让文字逐步停留，也不要一开始就出现表单。此处的目标是让玩家先把自己放入世界。

### 5.2 闻钟接引

```text
暗场与雨意
  -> 铜灯所在位置先亮
  -> 闻钟全身渐显
  -> 对话推进
  -> 留名 / 暂不留名
```

闻钟不是系统提示器。她的语言可以温柔而节制，但不得隐瞒产品事实。

### 5.3 道途引路人授法

```text
选择道途
  -> 对应光源初显
  -> 全身角色显形
  -> 引路人说明道途
  -> 三卷初法入册
```

五位引路人规格必须统一：全屏、完整对话、光源合理、无需头像层补充。

### 5.4 授法后入室

```text
引路人画面仍在
  -> 余光收拢，夜幕覆盖角色
  -> “三卷初法”确认
  -> 随灯入室
  -> 静室底图显出，界面仍隐藏
  -> 告知第一课仍待亲手开始
  -> 玩家确认，首页信息分层显现
```

这段演出的验收底线：不能产生“我还没做任何事，画面却告诉我已经修炼成功”的错觉。

## 6. 首页环境反馈

首页是玩家最常停留的修行之所，应以逐层回应代替频繁弹窗：

| 玩家行为 | 可见反馈方向 | 状态 |
|---|---|---|
| 初入静室 | 灯火候行、人物端坐但不作完成表态 | 已接入 |
| 完成首门真实功课 | 灯火加暖、气息首次稳定、完整首次引气演出 | 已有结构，待强化 |
| 连续守行 | 雨幕、案上物件、灯火稳定度逐步变化 | 已接入基础反馈，可扩充 |
| 中断归来 | 画面先给可开始的一分钟起念，不表现惩罚 | 已接入方向 |
| 境界突破 | 法相与环境共同形成一次明确变化 | 炼气 / 筑基阶段推进中 |

「雨痕退寸」是好的叙事意象，但当前若只让雨势轻微变化，会难以辨认。下一轮应增加至少一个清晰的视觉参照，例如窗棂雨痕位置、灯照范围或案沿积水退线，让玩家无需说明也看得出变化。

## 7. 法相与特效边界

- 炼气的灵气紧贴身体，初期近乎不可见，圆满仍应克制。
- 筑基以稳定道基外环和丹田紫焰建立新识别符号，不靠单纯增亮。
- 粒子数量宁少勿乱；气息应该有方向和呼吸，而不是覆盖画面的尘点。
- 大境界视觉应有明显增量，小境界只改变凝实度、节奏和局部结构。

境界细则见 [法相进阶设定.md](./法相进阶设定.md)。

## 8. 新资产制作规范

### 8.1 命名

```text
assets/mentors/{pinyin-name}-{purpose}-v{number}.webp
assets/generated/{feature}-{variant}-v{number}.webp
assets/{screen}-{element}-v{number}.webp
```

示例：`assets/mentors/shibuyan-lantern-entrance-v2.webp`。

### 8.2 角色生图要求

- 输出竖屏全身图，保留安全边距，适合移动端 `cover`。
- 人物服饰、法器、姿态必须对应角色气质和道途。
- 明确指定一个灯光来源及其大致构图位置。
- 背景统一位于听雨山门体系：雨、石阶、檐廊、静室或夜色山景。
- 禁止图片内文字、水印、按钮、边框、对话框或发光 UI 符号。
- 一次只解决一个角色或一场演出，不用杂糅风格套图冒充定稿。

### 8.3 接入流程

1. 先把资产作为候选放入对应目录，记录用途与版本。
2. 在真实页面以 `cover` 查看窄屏和长屏裁切。
3. 对齐光源、对话遮挡与转场层级。
4. 在五条道途至少各跑一次关联过场。
5. 通过后才写入正式资源缓存和制作总览；废弃稿标为留档或删除。

## 9. 后续美术制作清单

### 优先

- 「首次引气」演出的灯火、气息与静室反应升级。
- 「雨痕退寸」更明确的前后状态画面或可动画化图层。
- 五名引路人在极窄与长屏设备上的裁切微调验收。
- 筑基初期与炼气圆满的实机辨识度确认。

### 中期

- 七日守行对应的书案、窗外雨势或灯芯状态组。
- 筑基之约与突破文书关键演出资产。
- 可用于卷宗/人物页的引路人设定补图，但不替代全身入场规格。

### 长期

- 金丹及后续境界法相资产。
- 新地域、新人物与宗门事件的场景基准。
- 宣传用主视觉与应用商店图，但需与实际体验保持同一审美承诺。

## 10. 美术验收速查

- 这张图是否仍像听雨山的世界，而非另一款游戏的海报？
- 玩家第一眼是否能找到叙事光源？
- 光源在页面过场中是否准确对齐？
- 全屏裁切后，人物面部、手部与法器是否仍完整可读？
- 对话框是否遮住了本场演出的关键视觉信息？
- 颗粒、光晕和灵气是否已经多到让画面发脏？
- 这项反馈是否来自真实行为，而不是提前奖励玩家？
- 若是低境界或日常节点，是否仍为未来的壮阔留出了空间？
